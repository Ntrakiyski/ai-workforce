# Installable Skills (future)

Reserve this folder for a compact, installable n8n workflow engineering skill (`SKILL.md` with agent metadata, references and validation scripts). Do not package a skill until at least the source-verified JSON contract, versioned node catalog, deterministic checks and staging fixtures are established.

The intended skill should read research and rules **selectively**, retrieve exact node capabilities, produce JSON and diagram artifacts, and require real test evidence before stating 'ready to deploy'.
