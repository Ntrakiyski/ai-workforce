# Reusable Workflow Patterns (future)

Planned groups: `api-integration`, `retry-backoff`, `error-recovery`, `pagination`, `subworkflows`, `human-approval`, `deduplication`, `rate-limiting`, `data-transformation`.

Each pattern should eventually contain `README.md` (contract and rationale), `workflow.json` (tested export), `manifest.json` (version and dependencies) and `tests/` fixtures. No validated workflow template is included yet.
